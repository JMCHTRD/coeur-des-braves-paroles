Aide-mémoire : Mettre à jour les concerts

  1. Après avoir modifié vos concerts, cliquez sur le bouton "Télécharger le fichier" ci-dessus.
  2. Dans le dossier de votre projet (coeur-des-braves-site), remplacez l'ancien concerts.json par le nouveau.
  3. Envoyez cette modification sur GitHub. Les changements seront pris en compte sur le site.
